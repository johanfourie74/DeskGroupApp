### Bug J — Hotkey migration guard
**File:** `src\DeskGroup\Services\PersistenceService.cs`

### Note L — Launch cursor spinner
**File:** `src\DeskGroup\ViewModels\ShortcutItemViewModel.cs`  
**Change:** `Launch()` now sets `Mouse.OverrideCursor = Cursors.AppStarting` immediately before process start, with a 4-second `DispatcherTimer` to reset. Cursor also reset immediately on exception.  
**Why:** No visual feedback for slow-launching apps made users double-click repeatedly.

### Bug I — SHChangeNotify after icon hide/restore
**File:** `src\DeskGroup\Services\DesktopIconService.cs`  
**Change:** Added `SHChangeNotify` P/Invoke (`SHCNE_DELETE=0x4`, `SHCNE_CREATE=0x2`, `SHCNF_PATH|SHCNF_FLUSH`). Called `NotifyShellDeleted()` after `File.Move` in `HideDesktopIcon()`, `NotifyShellCreated()` after restore and orphan-restore.  
**Why:** Windows 11 Explorer no longer auto-refreshes the desktop after file moves — icons stayed visible after being added to a group, appearing duplicated.

### Note K — Tray "Restart DeskGroup" menu item
**File:** `src\DeskGroup\App.xaml.cs`  
**Change:** Added "Restart DeskGroup" `MenuItem` in `BuildTrayContextMenu()` above "Exit". Click handler: `MessageBox.Show` confirm → `_mainViewModel.SaveAllAsync()` → `Process.Start(Environment.ProcessPath)` → `Shutdown()`. Also added `using System.Diagnostics`.  
**Why:** Users had no easy way to restart the app after changing settings that require a restart.

### Note A — `--show-all` IPC end-to-end
**File:** `src\DeskGroup\App.xaml.cs`  
**Change:** Three additions:
1. `bool showAllGroups = e.Args.Contains("--show-all")` in `OnStartup`
2. `NamedPipeServer.TrySend("--show-all")` in second-instance path when `showAllGroups` is true
3. Pipe receiver: `if (msg == "--show-all") _mainViewModel?.ShowAllGroupsCommand.Execute(null)`

**Why:** Double-clicking the desktop/taskbar shortcut when app is already running now correctly shows all groups instead of silently exiting.

---

### Bug C — AllGroupsVisible sync on startup
**File:** `src\DeskGroup\ViewModels\MainViewModel.cs`  
**Change:** Added `AllGroupsVisible = _groupModels.Count == 0 || _groupModels.Any(g => g.IsVisible);` at the end of `InitializeAsync()`.  
**Why:** `AllGroupsVisible` defaulted to `true` but groups may have been saved as hidden. First tray-click saw `true` → called `HideAllGroups()` → groups that were already hidden "vanished again". Fix syncs the flag from actual loaded state.
